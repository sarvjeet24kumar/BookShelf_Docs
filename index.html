BookShelf Technical Documentation

Project Overview

BookShelf is a multi-tenant Django REST Framework (DRF) backend for managing digital libraries across multiple organizations. It provides a secure, scalable platform with complete data isolation, role-based access control, email verification, subscription management, and background task processing.

Features

Core Architecture

  • Multi-tenancy – Complete data isolation between organizations
  • UUID primary keys – All models use UUIDs for security and scalability
  • Background tasks – Celery with Redis for async email processing
  • Tenant context isolation – Middleware-based tenant enforcement on every request
  • Rate limiting – Authentication endpoints protected
  • Utility functions – Centralized user lookup and tenant validation utilities

Authentication & Authorization

  • Email/username authentication – Flexible login with either identifier
  • Email verification – Required OTP verification for new registrations
  • OTP login flow – Two-factor authentication (password + OTP)
  • Password reset – Secure token-based password reset via email
  • JWT tokens – Using SimpleJWT with token blacklisting on logout
  • Role-based access control – Super Admin, Admin, and User roles
  • Tenant isolation – SuperAdmin lookup enforcement (no tenant required)

Book Management

  • Tenant-scoped catalog – Books are managed per organization
  • Personal library – Track reading progress per user
  • Status tracking – TO_READ, READING, COMPLETED
  • Book requests – Users can request new books for admin approval
  • Approval workflow – PENDING → APPROVED / REJECTED states
  • Advanced filtering – Filter by status, genre, author, publication year
  • Genre management – Admin-controlled genre catalog
  • Free tier limits – Max 5 books for free users, unlimited for premium

Payments & Subscriptions

  • Razorpay integration – Secure payment gateway
  • Premium subscriptions – Unlock unlimited library entries
  • Subscription management – Track status and billing per tenant
  • Payment verification – Secure signature verification
  • Webhook handling – Automatic payment status updates
  • Idempotency – Prevent duplicate charges with unique order IDs
  • Checkout flow – Embedded Razorpay UI with auto-order creation

Logging & Error Handling

  • Structured logging – Logger instances in all views and services
  • Standardized error responses – Consistent JSON format via custom exception handler
  • Proper HTTP status codes – RESTful status codes for all scenarios
  • Exception hierarchy – success: false, error: {code, message, details} format
  • Middleware-based handling – Tenant validation and 404/500 handlers

Architecture Overview

Multi-Tenancy

BookShelf uses a shared database, shared schema multi-tenancy model where:

  • All data is scoped to a tenant via foreign keys
  • Users belong to a single tenant (except SuperAdmins with tenant_id=NULL)
  • Admins can only manage users and books within their tenant
  • SuperAdmins can manage platform-wide resources
  • Automatic tenant context – TenantMiddleware enforces context on every authenticated request
  • Query filtering – Custom managers auto-filter by tenant
  • Validation – Blocks access to suspended or deleted tenants

Role Hierarchy

Role Hierarchy

SUPER_ADMIN

  • Platform owner with system-wide access

  • Creates and manages tenant organizations

  • Views aggregated metrics (user/book counts only)

  • Cannot access individual user data or book details

  • No tenant assignment (tenant_id = NULL)

ADMIN

  • Organization manager with full tenant control

  • Manages users within their organization

  • Curates book catalog (approve/reject requests)

  • Controls genre taxonomy

  • Handles subscription upgrades

USER

  • Standard member with personal library management

  • Builds and manages personal bookshelf

  • Submits new book requests for approval

  • Tracks reading progress across collection

  • Access limited to organization's approved catalog

Tech Stack

Backend

  • Python 3.13+
  • Django 6.0
  • Django REST Framework 3.16+
  • PostgreSQL – Primary database
  • Redis – Caching and Celery broker
  • Celery – Background email tasks
  • uv – Fast Python package installer and runner

Security & Authentication

  • SimpleJWT – JWT token management with blacklisting
  • OTP system – Email-based two-factor authentication

Payments

  • Razorpay SDK – Payment gateway integration
  • Webhook verification – Signature-based security
