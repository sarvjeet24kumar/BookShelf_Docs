Tenant Onboarding Guide

What is a Tenant?

A tenant represents an organization or company using the BookShelf platform. Each tenant has its own isolated space with separate users, books, and data.

Onboarding Process

Step 1: Tenant Creation (By Super Admin)

The platform Super Admin creates the tenant with:

  • Name: Organization's display name

  • Slug: Unique URL identifier (auto-generated or custom)

  • Subscription Plan: Defaults to Free tier

After creation, the tenant receives a unique ID used for all API requests.

Step 2: Admin Account Setup

The Super Admin creates the first admin user for the new tenant:

  1. Super Admin provides:
  2. Admin's email address
  3. Username
  4. Temporary password

  5. Role set as ADMIN

  6. System actions:

  7. Creates admin user linked to the tenant
  8. Sends email verification OTP

  9. Admin verifies email and activates account

  10. Admin can now login using the Tenant-ID header

Step 3: Initial Configuration

The tenant admin sets up the organization:

Task Description
Add Genres Create book categories relevant to the organization
Invite Users Create user accounts or share signup instructions
Add Books Build the initial book catalog
Review Settings Configure any tenant-specific preferences

Step 4: User Signup

Regular users join the tenant:

  1. User visits signup page with Tenant-ID
  2. Submits email, username, and password
  3. Receives email verification OTP
  4. Verifies email to activate account
  5. Can now login and access tenant resources

Tenant Lifecycle

Free Tier Limits

  • Maximum 5 books per user in personal library
  • All core features available

Premium Upgrade

  1. Tenant admin initiates payment through checkout
  2. Razorpay processes the payment
  3. On success, tenant upgraded to Premium
  4. Users get unlimited library capacity

Tenant Status

Status Meaning
Active Fully operational, users can access
Inactive Suspended, users cannot login
Deleted Soft-deleted, pending permanent removal

Data Isolation

Each tenant's data is completely isolated:

  • Users can only see books within their tenant
  • Genres are tenant-specific
  • Personal libraries are scoped to tenant
  • No cross-tenant data access possible

Quick Reference

For Super Admin

  1. Create tenant via API or admin panel
  2. Create admin user for the tenant
  3. Share tenant credentials with organization

For Tenant Admin

  1. Verify email and login
  2. Set up genres and initial books
  3. Invite team members
  4. Manage user accounts and content

For Users

  1. Receive invite or signup URL with Tenant-ID
  2. Complete registration and email verification
  3. Login and start using the platform
  4. Browse books and build personal library

Support

If issues occur during onboarding:

  • Super Admin handles tenant-level issues
  • Tenant Admin handles user-level issues
  • Users contact their Tenant Admin
