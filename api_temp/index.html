API Endpoints

Authentication Endpoints

# Method Endpoint Access Description
1 POST /auth/signup/ Public Register new user account
2 POST /auth/verify-email/ Public Verify email with OTP
3 POST /auth/resend-otp/ Public Resend verification OTP
4 POST /auth/login/ Public Initiate login (send OTP)
5 POST /auth/verify-login/ Public Complete login with OTP
6 POST /auth/refresh/ Refresh Token Get new access token
7 POST /auth/logout/ Authenticated Logout and blacklist token
8 POST /auth/forgot-password/ Public Request password reset
9 POST /auth/reset-password/ Public Reset password with token
10 POST /auth/change-password/ Authenticated Change password

User Management Endpoints

# Method Endpoint Access Description
11 GET /users/ Admin, Super Admin List users
12 POST /users/ Admin, Super Admin Create new user
13 GET /users/<id>/ User (own), Admin, Super Admin Get user details
14 PATCH /users/<id>/ User (own), Admin, Super Admin Update user information
15 DELETE /users/<id>/ User (own), Admin, Super Admin Delete user account

User Update Permissions:

  • User: Own account only

  • Admin: Own + users in tenant

  • Super Admin: Own + tenant admins only

User Delete Permissions:

  • User: Own account only

  • Admin: Users in tenant (not self, not admins)

  • Super Admin: Tenant admins only (not users, not self)

Book Management Endpoints

# Method Endpoint Access Description
16 GET /books/ User, Admin List books
17 POST /books/ User, Admin Create book/request
18 GET /books/<id>/ User, Admin Get book details
19 PATCH /books/<id>/ User (pending), Admin Update book
20 DELETE /books/<id>/ Admin Delete book

Book View Permissions:

  • User: Approved books + own pending books

  • Admin: All books in tenant

Book Approval:

  • User: Creates with PENDING status

  • Admin: Can create pre-approved books, approve/reject requests

User Library Endpoints

# Method Endpoint Access Description
21 GET /users/<user_id>/books/ User (own), Admin List user's library
22 POST /users/<user_id>/books/ User (own), Admin Add book to library
23 GET /users/<user_id>/books/<book_id>/ User (own), Admin Get library book details
24 PATCH /users/<user_id>/books/<book_id>/ User (own), Admin Update reading status
25 DELETE /users/<user_id>/books/<book_id>/ User (own), Admin Remove book from library

Library Access:

  • User: Own library only

  • Admin: Any user library in their tenant

  • Super Admin: No access

Subscription Limits:

  • Free Plan: Max 5 books

  • Premium Plan: Unlimited books

Access

Role Description
Public No authentication required
Authenticated Any authenticated user
User Regular tenant member
Admin Tenant administrator
Super Admin Platform administrator
Refresh Token Valid refresh token required
Public (Signed) No auth but requires valid signature

Parameter Endpoints Description

status User books Filter by reading status
