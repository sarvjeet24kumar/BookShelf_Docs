Permissions Matrix

Platform/Tenant Management

Action Super Admin Admin User
Create tenant Yes No No
View all tenants Yes No No
Update tenant (subscription, features) Yes No No
Suspend/Delete tenant Yes No No
View tenant metrics (counts only) Yes No No
Access tenant's actual data (PII) No No No

User Management

Action Super Admin Admin User
Create admin for any tenant Yes No No
Create user in their tenant No Yes No
List all users in tenant No Yes No
View any user in tenant No Yes No
View own profile Yes Yes Yes
Update any admin in any tenant Yes No No
Update any user in tenant No Yes No
Update own profile Yes Yes Yes
Delete any tenant admin Yes No No
Delete any user in tenant No Yes No
Delete own account No No Yes
Suspend/Unsuspend user No Yes No
Override: Restore deleted user No Yes No

Key Rules:

  • Super Admin: Can only manage tenant admins, not regular users or their data

  • Admin: Cannot delete or update themselves, other admins, or super admins

  • User: Can only delete own account, cannot update/delete admin accounts

Book Management

Action Super Admin Admin User
View all books in tenant No Yes No
View approved books No Yes Yes
View own pending/rejected books No Yes Yes
Create book (auto-approved) No Yes No
Request book (pending) No Yes Yes
Update any book No Yes No
Update own pending book No Yes Yes
Delete any book No Yes No
Approve/Reject book request No Yes No
Override: Restore deleted book No Yes No
Override: Change rejected → approved No Yes No

Key Rules:

  • User books start with PENDING status (require admin approval)

  • Admin can create pre-approved books with APPROVED status

  • User can only update their own books while in PENDING status

  • Once approved/rejected, only Admin can modify
