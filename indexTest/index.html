BookShelf – Multi-Tenant Library Management Platform

A secure, scalable platform for managing digital libraries across multiple organizations with role-based access control and subscription management.

Overview

BookShelf is a multi-tenant REST API platform built with Django REST Framework that enables multiple organizations (libraries, schools, companies) to manage their book collections with complete data isolation.

Key Goals

  • Multi-tenant – Serve multiple organizations from one deployment
  • Complete data isolation – Tenant-level query filtering and middleware enforcement
  • 3-tier role system – Super Admins, Tenant Admins, Regular Users
  • Subscription-based – Free and Premium
  • Security – JWT + OTP 2FA, token blacklisting, rate limiting
  • Personal libraries – Users track reading status (TO_READ, READING, COMPLETED)

Multi-Tenant Architecture

Isolation Mechanism

  • Database-level: All records tagged with tenant_id
  • Middleware: TenantMiddleware enforces context on every authenticated request
  • Query filtering: Automatic tenant filtering via custom managers
  • Validation: Blocks access to suspended/deleted tenants

Role-Based Access Control

Role Hierarchy

SUPER_ADMIN - Manages tenants (no PII access)

ADMIN - Full control within tenant

USER - Own library only

Key Features

Platform Management

  • Multi-tenant infrastructure
  • Platform-wide analytics (counts only)
  • Subscription

Authentication & Security

  • Email-based signup with OTP verification
  • 2FA login (password + OTP)
  • JWT tokens with refresh + blacklisting
  • Rate limiting
  • Password reset via secure email tokens

User Management

  • Self-service registration
  • 3-tier role system (Super Admin, Admin, User)
  • Profile management

Technology Stack

Backend

  • Django 6.0 + Django REST Framework

  • PostgreSQL

  • Redis (caching + Celery broker)

  • Celery (async email tasks)

Security

  • Simple JWT (token management)

  • OTP system (email-based 2FA)

  • Token blacklist (logout)

Payments

  • Razorpay (payment gateway)
  • Webhook verification
