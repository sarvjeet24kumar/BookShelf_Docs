BookShelf – Multi-Tenant Library Management Platform

A secure, scalable platform for managing digital libraries across multiple organizations with role-based access control and subscription management.

Overview

BookShelf is a multi-tenant REST API platform built with Django REST Framework that enables multiple organizations (libraries, schools, companies) to manage their book collections with complete data isolation.

Key Goals

  • Multi-tenant – Serve multiple organizations from one deployment
  • Complete data isolation – Tenant-level query filtering and middleware enforcement
  • 3-tier role system – Super Admins, Tenant Admins, Regular Users
  • Subscription-based – Free and Premium
  • Security – JWT + OTP 2FA, token blacklisting, rate limiting
  • Personal libraries – Users track reading status (TO_READ, READING, COMPLETED)

Multi-Tenant Architecture

Isolation Mechanism

  • Database-level: All records tagged with tenant_id
  • Middleware: TenantMiddleware enforces context on every authenticated request
  • Query filtering: Automatic tenant filtering via custom managers
  • Validation: Blocks access to suspended/deleted tenants

Role-Based Access Control

Role Hierarchy

SUPER_ADMIN - Manages tenants (no PII access)

ADMIN - Full control within tenant

USER - Own library only

Full permissions: API_DOCUMENTATION.md

Key Features

Platform Management

  • Multi-tenant infrastructure
  • Platform-wide analytics (counts only)
  • Subscription

Authentication & Security

  • Email-based signup with OTP verification
  • 2FA login (password + OTP)
  • JWT tokens with refresh + blacklisting
  • Rate limiting
  • Password reset via secure email tokens

User Management

  • Self-service registration
  • 3-tier role system (Super Admin, Admin, User)
  • Profile management

Technology Stack

Backend

  • Django 6.0 + Django REST Framework

  • PostgreSQL

  • Redis (caching + Celery broker)

  • Celery (async email tasks)

Security

  • Simple JWT (token management)

  • OTP system (email-based 2FA)

  • Token blacklist (logout)

Payments

  • Razorpay (payment gateway)
  • Webhook verification

System Workflows

Authentication Flow

User Signup:

  • User submits registration form with credentials

  • System validates data and creates pending account

  • OTP (6-digit code) sent to user's email

  • User enters OTP to verify email ownership

  • Account status changes to active

  • User can now log in

User Login:

  • User provides email/username and password

  • System validates credentials

  • OTP sent to user's email (2FA)

  • User enters OTP within validity period

  • System issues JWT tokens (access + refresh)

  • User authenticated for API access

Password Reset:

  • User requests password reset via email

  • System sends secure reset link with token

  • User clicks link and provides new password

  • Password updated and user can log in

Book Management Flow

User Book Request:

  • User searches catalog for book

  • If not found, user submits new book request

  • Book created with status: PENDING

  • Admin receives notification

  • User can view/edit their pending request

Admin Book Approval:

  • Admin reviews pending book requests

  • Admin can approve - Status changes to APPROVED

  • Book becomes visible to all tenant users

  • User receives approval notification email

Admin Book Rejection:

  • Admin can reject Status changes to REJECTED

  • Book remains visible only to creator

  • User receives rejection notification email

  • User can edit and resubmit if needed

Admin Direct Creation:

  • Admin creates book directly

  • Book auto-approved with status: APPROVED

  • Immediately visible to all users

  • No approval workflow needed

Subscription & Payment Flow

Payment Initiation:

  • Tenant Admin accesses checkout page

  • System checks if tenant already has active subscription

  • If not active, Razorpay order created automatically

  • Order details displayed on checkout page

Payment Processing:

  • User completes payment via Razorpay UI

  • Razorpay processes transaction

  • Payment status tracked in database

Webhook Verification:

  • Razorpay sends webhook to /payments/webhook/razorpay/

  • System verifies webhook signature (security check)

  • If signature valid, payment marked as SUCCESS

  • Subscription status updated to ACTIVE

  • All tenant users gain Premium features

Premium Activation:

  • Subscription status: CREATED to ACTIVE

  • Library limit: 5 books to Unlimited

  • Premium features unlocked for entire tenant

Stakeholders

Super Admins (Platform Owners)

  • Create and manage tenants

  • Monitor platform metrics (no PII)

  • View subscriptions and billing

  • View payment/webhook history

Tenant Admins (Organization Managers)

  • Manage users in their organization

  • Build book catalog

  • Approve/reject book requests

  • Manage genres

  • Initiate subscription payments

Users (Library Members)

  • Maintain personal bookshelf

  • Track reading progress

  • Request new books

  • Search and filter approved books
