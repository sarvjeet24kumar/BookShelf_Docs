Functional Documentation: BookShelf Multi-Tenant System

1. Authentication & Multi-Tenancy Module

  • Tenant-Aware Authentication: Secure JWT-based registration and login that automatically identifies the user's organization (Tenant).
  • Tenant Isolation: All requests are validated against the tenant status (Active/Suspended/Deleted) before processing.
  • Secure Credentials: Password hashing and validation using Django's standard security framework.
  • Role-Based Access: Specialized roles (Super Admin, Tenant Admin, User) with specific access levels.

2. Tenant Management Module (Platform Level)

  • Lifecycle Management: Super Admins can create, update, and manage multiple tenants.
  • Soft Deletion Protocol: Tenants can be marked as deleted, which immediately blocks access for all associated users.
  • Delayed Data Purge: A background cron job automatically purges all related data (Users, Books, Genres, etc.) after retention period, keeping the platform clean while allowing for recovery.
  • Restore Capability: Super Admins can restore deleted tenants (and their data) any time before the final purge.

3. Book & Genre Management Module

  • Content Organization: Management of books and genres within a tenant's isolated environment.
  • Data Integrity: Validation for required fields (Title, Author, ISBN, Published Year) and unique constraints per tenant.
  • Tenant-Isolated Library: Admins and Users only see books belonging to their specific organization.

4. Reading Status Tracking Module

  • Personal Bookshelves: Users can add books to their personal library and track reading progress.
  • Predefined Statuses:
  • TO_READ: Books planned for the future.
  • READING: Currently active books.
  • COMPLETED: Finished reading material.

5. Access Control & Permission Module

  • Ownership Enforcement: Users can only manage their own personal library and reading status.

  • Tenant Admins: Manage users and books within their own tenant.

  • Super Admins: Perform platform-wide operations, manage all tenants, and oversee Admin users across the system.
  • Cross-Tenant Security: Prevention of unauthorized access between different organizations.

6. Payment & Subscription Module

  • Transaction Processing: Integrated Razorpay payment gateway for subscription management.
  • Webhook Handling: Automated background processing of payment events (success, failure, capture).
  • Payment Reconciliation: Automated cron jobs to ensure system records match external gateway states.
